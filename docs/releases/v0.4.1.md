Fixes the Ubuntu 26.04 install and adds a one-line installer.

## Install

On Ubuntu/Debian (amd64, arm64) or an Apple silicon Mac:

```sh
curl -fsSL https://raw.githubusercontent.com/mohyt/chintu/main/install.sh | bash
```

The script picks the package for the computer, checks its SHA-256 and starts the tray. The APK is below; it installs over 0.4.0.

## Packages

- `chintu-0.4.1.apk`: the Android companion (Android 12+), signed with the Chintu release key.
- `Chintu-0.4.1-arm64.dmg`: the macOS menu-bar app with the gateway daemon. Ad-hoc signed; the installer clears quarantine, a manual install needs right-click → Open.
- `chintu-desktop_0.4.1_amd64.deb` and `chintu-desktop_0.4.1_arm64.deb`: tray and daemon for Ubuntu 24.04 and 26.04 and Debian 13.
- `install.sh` and `SHA256SUMS`.

## Changes

- Debian package: bundles the compiled wheels for Python 3.12, 3.13 and 3.14 and installs the set for the system Python. 0.4.0 carried only 3.12 wheels and failed on Ubuntu 26.04 with "cffi … is not a supported wheel on this platform".
- One-line installer (`install.sh`) for Ubuntu/Debian and macOS.
- Dependencies: FastAPI 0.143.0, Starlette 1.8.0, Kotlin 2.4.21, Android Gradle plugin 9.4.1 with Gradle 9.8.1, current GitHub Actions.
- Repository: public, with a security policy, secret scanning and branch protection on `main`.
