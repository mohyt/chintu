Voice notes in the shared OKF format, so Ataria can read them.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/mohyt/chintu/main/install.sh | bash
```

On Ubuntu this upgrades the desktop companion and gateway in place; quit and reopen the tray (or
log out and in) so the new gateway starts. The phone app is unchanged apart from its version;
`chintu-0.6.0.apk` installs over 0.5.x and keeps your pairings.

## New

- **Notes are OKF files.** Each finished voice note is a Markdown file with YAML frontmatter
  (`type`, `id`, `title`, start and finish times, word count, `generated`, `sources`) in a notes
  folder that also holds `index.md` and `log.md`. This is the OKF v0.2 format Ataria and the
  vault use (`docs/12-okf-notes.md`, decision D22). The note text itself is unchanged.
- **`DATA_HOME`.** When the operator config has no `notes_dir`, notes go to
  `$DATA_HOME/00-Inbox/Notes` if the machine sets `DATA_HOME` (in the environment or as
  `DATA_HOME=<path>` in `~/.config/ataria/data.env`), otherwise beside the gateway database as
  before. An explicit `notes_dir` still wins, so existing setups keep writing where they do now.

## Upgrade notes

- Notes written by 0.5.x and earlier stay as they are; readers accept both.
- The agent persona now tells Claude that `index.md` and `log.md` in the notes folder are not
  notes.
