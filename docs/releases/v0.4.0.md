First packaged release of Chintu: Conversational Hands-free Interface to Networked Terminals & Utilities.

## Packages

- `chintu-0.4.0.apk`: the Android companion (Android 12+), signed with the Chintu release key.
- `Chintu-0.4.0-arm64.dmg`: the macOS menu-bar app with the gateway daemon and the Claude Agent SDK inside. Ad-hoc signed; first launch needs right-click → Open.
- `chintu-desktop_0.4.0_amd64.deb` and `chintu-desktop_0.4.0_arm64.deb`: the same tray and daemon for Ubuntu 24.04.

## What is in it

- Voice companion: Jarvis-style reactive orb, Bluetooth headset routing, spoken replies, location-aware greeting, interim narration while the daemon works, quiet mode with an activity page, and a note-taking mode that streams dictation straight into Markdown files.
- Gateway daemon on the Claude Agent SDK with `inspect`, `develop` and `desktop` profiles; workspace confinement for the first two; pairing by QR from the desktop app over Tailscale.
- Desktop tray for macOS and Ubuntu: phone connection status, QR pairing window, gateway supervision, Tailscale Serve, paired-phone revocation, login autostart.
- Security hardening from the first review: owner-only local endpoints, token expiry and revocation, per-phone task isolation, private lock-screen notifications.

See `docs/11-packaging-and-releases.md` for installation notes and where an installed Chintu keeps its files.
