Fixes found while installing Chintu on a fresh Ubuntu 26.04 desktop.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/mohyt/chintu/main/install.sh | bash
```

The APK below installs over 0.4.x.

## Changes

- Port conflicts: when another program already listens on 127.0.0.1:8765 (for example a local MCP server in Docker), the tray moves the gateway to the first free port from 8766 to 8799, saves it in `desktop.json` in the Chintu folder and says so in the menu. Tailscale Serve, pairing and `chintu-desktop status` follow the saved port, so no launcher needs editing. An explicit `--port` still wins.
- Tailscale Serve on Linux: when `tailscale serve` is refused because the user is not the Tailscale operator, the tray shows the exact `sudo tailscale set --operator=<user>` command, and `install.sh` warns about it up front.
- Ubuntu notifications now show the Chintu name and icon. pystray sent an empty app name and a temporary icon file, so GNOME showed neither.
