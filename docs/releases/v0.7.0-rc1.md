The first test release of 0.7.0, the release that brings Ataria's daily board into Chintu. This is a **pre-release**: the plain installer and the "latest" release stay on 0.6.0 until 0.7.0 itself.

## Install or upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/mohyt/chintu/main/install.sh | bash -s -- --pre
```

The installer now stops the running Chintu (tray and gateway), upgrades it, offers to set up Ataria, and starts Chintu again, also when you run it over SSH. `chintu-0.7.0-rc1.apk` installs over 0.6.0 and keeps your pairings.

## New

- **Conversations shared by voice and chat** (#27). Voice and typed messages continue one conversation and its agent session, with a WhatsApp-style chat list, a working folder per chat, a tools sheet, and replies streamed while the agent works.
- **The Ataria board on the phone** (#41). A ✓ button opens the Today sheet (Needs you, Today, Later, Digest, Done) from the computer's Ataria engine; ticking an item marks it done there. The gateway reaches the engine only on loopback, and the button appears only when the computer has one.
- **Ataria setup** (#42 and this release). Everything personal Ataria needs lives in a local `ataria.json`, never in the code:
  - `chintu-desktop ataria init` asks for it section by section (you, vault, schedule, agents, work, family, sources, delivery, notes for the agents, secret references, privacy). Run it again to change answers.
  - `chintu-desktop ataria doctor` checks the profile, the vault, the agents' sign-ins and secret references.
  - The installer runs `init` on a first install if you agree, and `doctor` on an upgrade.
- **Installer options:** `--pre`, `--version X.Y.Z[-rcN]`, `--file PATH` (a package you already have), `--force`, `--ataria` / `--no-ataria` and `--no-start`. It reports the installed and new versions and does nothing when you are already up to date.

## Not in this test release

The Ataria engine itself (the scheduled jobs, the merge and the app server) still runs from the owner's existing setup; it moves into Chintu in the next candidates, and 0.7.0 ships when one install sets up both.

## Upgrade notes

- Version numbers: a candidate is `X.Y.Z-rcN` in the `VERSION` file and on tags, `X.Y.ZrcN` in the Python packages and `X.Y.Z~rcN` in the Debian package, so 0.7.0 installs over every 0.7.0 candidate.
- The packages now include the `chintu-ataria` Python package and PyYAML.
